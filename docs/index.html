About this launchpad

    

    
Leonida Launchpad is a static frontend for the Ammora V4 launch system on GIWA
    Sepolia. It imports the official Ammora SDK (@ammora-protocol/sdk@0.3.9)
    and viem, reads the live deployment catalog, lists real launches from
    on-chain events, quotes trades with the SDK curve client, and builds unsigned
    create/swap transactions that only your connected wallet can sign.

    
There is no backend, no database, no API key and no mock data. If the RPC is
    unreachable, the page says so instead of showing invented numbers.

    
Live deployment (auto-route, GIWA Sepolia 91342)
